DotReportSync

A personal Windows utility that copies two user-selected local JSON reports to separate, private files in the owner's Google Drive.

The desktop utility validates JSON before uploading, updates fixed copies when content changes, and never writes back to the source reports. It uses the Google Drive API's drive.file permission to manage files created by the application. It does not require a mounted Drive or a running browser.

This website provides documentation only. It does not accept uploads, display report contents, or handle Google sign-in. Authorization happens through Google's official consent screen from the local desktop utility.

The application is for its owner's personal use and is not offered as a public hosted service.
