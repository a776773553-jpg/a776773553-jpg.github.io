Privacy policy

Effective November 6, 2026. DotReportSync is a personal Windows report synchronization utility.

Data accessed and used

The utility reads exactly two locally configured JSON reports, the authorized Google account's email and identity metadata, and metadata, permissions, and content checksums for its application-created Drive folders and files. Account information verifies the intended owner. Report content is used only to create or update the owner's private Drive copies.

Permissions and transfers

The utility requests https://www.googleapis.com/auth/drive.file. This scope permits managing files created by the application or explicitly made available to it by the user; this utility operates only on its own designated report copies and folders. Report bytes are sent over HTTPS to Google Drive. The utility does not sell data, use it for advertising or AI training, or transmit reports to GitHub or a developer-operated server. Other tools access Drive copies only through the user's separately granted authorization.

Storage and protection

OAuth access and refresh tokens are encrypted on the Windows computer using current-user Windows DPAPI. Local status records contain timestamps, file identifiers, hashes, links, and sanitized errors, not report bodies or tokens. No extra local historical report copies are intentionally retained. Google Drive may retain file revisions under its own policies. Source files remain under the user's control and are not modified by synchronization.

Retention and control

The user may disable the dedicated Windows scheduled task to stop synchronization, revoke DotReportSync access in Google Account third-party connections, and delete cloud copies or local credentials separately. Stopping synchronization or revoking access does not automatically delete existing files. Cloud retention and deletion follow Google's policies.

Website and contact
